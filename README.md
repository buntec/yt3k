# yt3k

A radically decluttered UI for YouTube, as a browser extension for Chrome, Edge,
Firefox and other Chromium browsers. Unlike other extensions, it doesn't alter the
YouTube page itself: its toolbar button opens an entirely new page with just your
subscriptions, your Home feed, Watch later and History, without Shorts or shelves,
using the YouTube account you're logged in with.

Built with [WXT](https://wxt.dev), React and [Astryx](https://astryx.atmeta.com).

It has these tabs:

- **Subs**: all subscribed channels ordered by their latest upload, each
  with its 3 most recent videos (no Shorts, with view counts and lengths) and an
  unsubscribe button. Hovering a video shows a **Save to Watch later** button. A search bar
  filters by channel name or video title (press `/` to focus it). The last loaded
  list shows right away and is brought up to date in the background, and again
  when you come back to its browser tab. Channels show 30 at a time, with more
  as you scroll.
- **Feed**: the videos YouTube recommends on its Home page (Shorts and other
  shelves are left out). Each video's menu has **Save to Watch later**, **Not
  interested** and **Don't recommend channel**, which do the same as on YouTube
  and can be undone.
- **Watch later**: the Watch later playlist, with **Remove from Watch later** in
  each video's menu, which can be undone too.
- **History**: the videos you watched, newest first under the day you watched
  them (Shorts are left out). Each video's menu has **Save to Watch later** and
  **Remove from watch history**, which can't be undone, like on YouTube. It loads
  again each time you open the tab.

In Feed, Watch later and History, scrolling to the bottom loads the next batch, and partly
watched videos show how far you got, like on YouTube.

Clicking a video plays it in an embedded player on the page; videos that can't be
embedded open on YouTube in a new tab instead. The player's minimize button shrinks
it into the bottom right corner, where it keeps playing while you browse, also
on the other tabs.

The theme switch in the top bar picks System, Light or Dark.

## Disclaimer

yt3k is an unofficial project, not affiliated with or endorsed by YouTube or
Google. It uses YouTube's internal web API, the one youtube.com itself uses,
which isn't documented and may change at any time, so parts of yt3k can stop
working until it's updated. Actions like unsubscribing or **Not interested**
apply to your YouTube account as if you'd done them on youtube.com. yt3k sends
your data only to YouTube and collects nothing itself. Use it at your own risk.

## Install

Download a build from the [releases](https://github.com/buntec/yt3k/releases):

- **Chrome** and other Chromium browsers (Brave, Opera, Vivaldi, …): unzip
  `yt3k-x.y.z-chrome.zip`, then in `chrome://extensions` enable **Developer mode**,
  click **Load unpacked** and select the unzipped folder.
- **Edge**: the same with `yt3k-x.y.z-edge.zip` in `edge://extensions`.
- **Firefox**: open `yt3k-x.y.z-firefox.xpi` in Firefox, if the release has one.
  Otherwise load `yt3k-x.y.z-firefox.zip` in `about:debugging` → **This Firefox** →
  **Load Temporary Add-on**; Firefox removes it again when it restarts.

## Development

```sh
npm install
npm run dev
```

Then in Chrome: `chrome://extensions` → enable **Developer mode** → **Load unpacked** →
select `.output/chrome-mv3-dev`. This only needs to be done once; while `npm run dev`
is running, the extension reloads automatically on save.

A local, gitignored `web-ext.config.ts` with `disabled: true` stops WXT from launching
a separate browser profile, so you stay logged in to YouTube in your normal one.

`npm test` runs the parser tests against anonymized YouTube data in `utils/__fixtures__/`,
whose README explains how to capture fresh data when YouTube changes.

`npx astryx` (the Astryx CLI) prints component docs, e.g. `npx astryx component Button`.
`astryx-themes.ts` is generated by `npx astryx theme add`; don't edit it by hand.

For day-to-day use without the dev server, run `npm run build` and load
`.output/chrome-mv3` instead.

`npm run dev:firefox` and `npm run build:firefox` do the same for Firefox
(`.output/firefox-mv3-dev` and `.output/firefox-mv3`). Load the extension in
`about:debugging` → **This Firefox** → **Load Temporary Add-on** by selecting the
`manifest.json` in that folder. Firefox removes it again when it restarts. Its
button starts out in the Extensions (puzzle-piece) menu; pin it to the toolbar from
there.

## Releasing

Pushing a tag like `v1.2.3` runs the release workflow, which builds the extension
with that version for Chrome, Edge and Firefox and publishes the builds as a GitHub
release. The version in `package.json` isn't used for releases.

For a signed Firefox add-on (the `.xpi`), add API credentials from
[addons.mozilla.org](https://addons.mozilla.org/developers/addon/api/key/) as the
repository secrets `AMO_JWT_ISSUER` and `AMO_JWT_SECRET`. The workflow then signs
the add-on for self-distribution (unlisted; it isn't published on the add-ons site).
